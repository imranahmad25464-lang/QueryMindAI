# QueryMind AI — Natural Language to SQL Assistant

**QueryMind AI** is an AI-powered database assistant that converts natural-language questions into SQL queries and retrieves results from a SQLite database through a web interface.

The project combines a local language model with a Flask backend to make database querying easier for users who may not know SQL.

## Features

- **Natural Language to SQL:** Ask database questions in plain English.
- **AI-Powered Query Generation:** Uses Ollama with the Qwen 2.5 1.5B model.
- **SQLite Database:** Works with sample employee and sales data.
- **Interactive Web Interface:** Enter questions and view generated SQL and query results.
- **Read-Only Query Execution:** Intended to restrict database operations to read-only queries.
- **Query Results Table:** Displays the retrieved data in the browser.

## Database

The application initializes a SQLite database named `querymind.db` with two tables.

### 1. Employees

Stores sample employee information, including:

- Employee ID
- Name
- Department
- Salary
- City

### 2. Sales

Stores sample sales information, including:

- Sales record ID
- Employee ID
- Product
- Sales amount
- Month

The `employee_id` field connects sales records to employees.

## Getting Started

### Prerequisites

Install the following:

- Python 3
- Git
- Ollama

### 1. Clone the repository

```bash
git clone https://github.com/imranahmad25464-lang/QueryMindAI.git
cd QueryMindAI
```

### 2. Create a virtual environment

**Windows PowerShell:**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, use the environment's Python executable directly as shown below.

### 3. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

### 4. Install the AI model

Make sure Ollama is installed and running, then execute:

```powershell
ollama pull qwen2.5:1.5b
```

### 5. Start the application

```powershell
python app.py
```

Open the following address in your browser:

http://127.0.0.1:5000

Keep the Flask server and Ollama running while using the application.

## Security Notes

- Use only trusted, non-sensitive sample data when experimenting.
- Review generated SQL before relying on query results.
- Read-only query restrictions are a safeguard, not a guarantee of production-grade security.
- Additional testing, stronger query validation, and appropriate access controls are needed before using real or sensitive business data.
